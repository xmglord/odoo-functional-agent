# Requirement (fixture for the purchase_inventory scenarios)

A small distributor buys stocked goods from vendors and pays only for what arrives. Trucks are unloaded at a dock,
counted, and only then put away on the shelves, so receipts must happen in two steps. Vendors sometimes deliver part
of an order; the rest is still expected and must stay open as a backorder.

(Fictional requirement used to set up a demo database before running the scenarios in
`scenarios/20.0/purchase_inventory/`. No real company data.)
